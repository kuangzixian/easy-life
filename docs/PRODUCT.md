# 好好生活 / 匡子闲学：首版产品约定

目标：用户能在一分钟内找到一条可理解、有出处的生活资料，并愿意在需要时回来。不是打卡任务清单，不用登录或充值，不承诺个性化专业建议。

## 三条核心路径

1. 不知道看什么：今天 → 今日建议或抽张卡 → 左右切换 → 收藏 / 看完整内容。
2. 想系统读：今天 → 从第一页开始 → 下一篇 → 退出 → 今天继续阅读；也可从慢慢读挑章节。
3. 已有具体问题：问一问 → 输入自然语言或关键词 → 看相关建议 → 打开原文及出处；无结果时换具体词或浏览目录。

卡片采用一次最多五条，前后按钮和手势并存；换一组优先避免当前组重复。主题少于五条时显示实际数量，不重复凑数。随机池只包含日常精力、时间、账号安全、放松和学习建议，共 40 条。搜索和顺序阅读仍覆盖全量 630 条。

## 视觉与文案

- 网页版名称：好好生活。
- 微信小程序审核名称：匡子闲学；简称使用同名，保持不变。
- 色彩：背景 `#F8F6EF`，墨绿 `#183F35`，点缀 `#DDEA9B`。
- 米白纸面、圆角卡片、细线与少量几何元素，不引入大图、外链字体或网络依赖。
- 用“原文评级”“相关建议”“阅读原文与出处”，不使用虚构的 AI 回答、审核认证或统计数据。
- 保留证据中的争议和限定条件；详情提供来源版本与可复制链接。
- 不把健康/法律/金融摘要包装成针对个人的诊疗、法律咨询或投资指令。

## 首版边界

| 已包含 | 以后另行设计 |
| --- | --- |
| 原生小程序、离线全书、检索、卡片、设备内收藏 | 生成式 AI 问答、账号同步、云服务 |
